VIDEO_EXPLAINER INFOGRAPHIC RULES

Do not create the same infographic for every reel.

For each reel, analyze:
- script
- transcript
- topic
- numbers
- branches
- process steps
- comparison logic
- risks
- benefits
- timeline scenes

Choose bottom visual explanation format based on script:

1. ACCUMULATIVE_FLOWCHART
Use when the script contains:
- numbers
- loans
- investments
- math
- split paths
- branches
- process steps
- decision trees
- cause-effect explanation

2. STEP_BY_STEP_LIST
Use when the script explains:
- sequence
- checklist
- tutorial
- exam process
- job process
- application process
- instructions

3. COMPARISON_SPLIT
Use when the script compares two things:
- debit vs credit
- job vs business
- SIP vs FD
- website vs web app

4. WARNING_RISK_MAP
Use when the script explains:
- fraud
- mistakes
- scams
- rejection reasons
- danger signs
- risks

5. SIMPLE_STAT_CARD
Use when the script focuses on:
- one big number
- salary
- amount
- percentage
- EMI
- interest rate
- score
- result

PERSISTENT STATE EXECUTION:
When a node, label, arrow, amount, icon, or text appears, it must remain visible until the end of that visual scene unless the scene explicitly changes topic.

Do not remove earlier nodes when the next node appears.

Timeline behavior:
- Beat 1: first/main node appears.
- Beat 2: second node appears, first stays.
- Beat 3: third node appears, first and second stay.
- Final beat: full infographic is visible.

AI output must include:
- visualType
- title
- nodes
- arrows
- revealStartSeconds
- revealEndSeconds
- emphasisLevel
- soundCueType
- layoutHint

Never repeat fixed demo examples like Loan Process for every reel.
Infographic content must come from the actual script.
