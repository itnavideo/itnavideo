# Countdown / Coming Soon Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | Countdown / Coming Soon |
| Internal ID | `COUNTDOWN_REEL` |
| Composition ID | `COUNTDOWN-REEL` |
| Dashboard Mode | `countdownReel` |
| Category | Business |

## Purpose

Launch teasers with countdown animation. For product launches, course releases, event countdowns, new video announcements.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Countdown/teaser visual treatment
- "Coming Soon" or "Launching In" messaging
- Building excitement/anticipation
- Works for any launch/announcement
- Details from transcript or form fields
- No background music by default
