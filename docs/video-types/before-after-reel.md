# Before / After Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | Before / After |
| Internal ID | `BEFORE_AFTER_REEL` |
| Composition ID | `BEFORE-AFTER-REEL` |
| Dashboard Mode | `beforeAfterReel` |
| Category | Business |

## Purpose

Dramatic before/after reveal animation. For transformations, results, makeovers, case studies.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |
| Before image | Image | Via upload |
| After image | Image | Via upload |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Split or reveal transition between before and after states
- Title/timeline text from form fields
- Dramatic reveal moment as key visual
- Works for: weight loss, renovation, design, business growth
- CTA at end (optional, from form)
