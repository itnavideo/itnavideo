# Testimonial / Review Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | Testimonial / Review |
| Internal ID | `TESTIMONIAL_REEL` |
| Composition ID | `TESTIMONIAL-REEL` |
| Dashboard Mode | `testimonialReel` |
| Category | Business |

## Purpose

Turn customer reviews and testimonials into social proof video reels. Stars, quotes, and trust signals.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Review/testimonial text from transcript
- Star rating visual element
- Customer quote highlight
- Trust-building layout
- Works for product reviews, service testimonials, course feedback
