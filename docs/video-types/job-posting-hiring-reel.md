# Job Posting / Hiring Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | Job Posting / Hiring |
| Internal ID | `JOB_POSTING_REEL` |
| Composition ID | `JOB-POSTING-REEL` |
| Dashboard Mode | `jobPostingReel` |
| Category | Business |

## Purpose

Post jobs with requirements and apply CTA in reel format. For HR teams, startups, and recruiters.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |
| Job title | Text | Via form |
| Company name | Text | Via form |
| Requirements | Text | Via form |
| Location | Text | Via form |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Job listing layout with title, company, requirements
- Apply CTA prominent
- Professional/corporate feel
- Requirements from form fields (not just transcript)
- Shareable format for LinkedIn/Instagram
