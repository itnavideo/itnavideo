# Event / Invite Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | Event / Invite |
| Internal ID | `EVENT_INVITE_REEL` |
| Composition ID | `EVENT-INVITE-REEL` |
| Dashboard Mode | `eventInviteReel` |
| Category | Business |

## Purpose

Announce events with date, venue, and CTA. For webinars, workshops, meetups, conferences, religious gatherings.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Event details layout (date, time, venue)
- RSVP/register CTA
- Excitement-building visual treatment
- Works for any event type
- Details from transcript or form fields
