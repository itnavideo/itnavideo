Create ranked list reels — "Top 5 Tools", "3 Best Tips", "7 Things to Avoid". Numbered, structured, engaging.

| Input | Type | Required |
|-------|------|----------|

## Key Rules
- Numbered/ranked list format
- Each item gets a visual scene/card
- Progress indicator showing item number
- Clean transitions between items
- Works with any topic from transcript
