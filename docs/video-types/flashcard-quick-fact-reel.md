Study flashcards with term and definition. For students, educators, and knowledge-sharing content.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Flashcard-style reveal (term → definition)
- Clean educational layout
- Multiple cards per video (from transcript segments)
- Study-friendly format viewers save
- Works for: vocabulary, facts, formulas, Q&A
