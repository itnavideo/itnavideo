# News Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | News Reel |
| Internal ID | `NEWS_REEL` |
| Composition ID | `NEWS-REEL` |
| Dashboard Mode | `newsReel` |
| Category | Trending |

## Purpose

Create trending news/current affairs reels with headline, key points, and urgency-driven layout.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- News-style layout with headline prominence
- Key points from transcript
- Urgency/breaking-news visual feel
- No background music by default
- Supports any language audio (captions in English/Hinglish)
