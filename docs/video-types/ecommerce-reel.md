# Ecommerce Reel

## Basic Information

| Field | Value |
|-------|-------|
| Video Type Name | Ecommerce Reel |
| Internal ID | `ECOMMERCE_REEL` |
| Composition ID | `ECOMMERCE-REEL` |
| Dashboard Mode | `ecommerceReel` |
| Category | Business |

## Purpose

Promote products with price, features, and CTA in a reel format. For online sellers, dropshippers, and small businesses.

## Required User Inputs

| Input | Type | Required |
|-------|------|----------|
| Audio/Video | Audio/Video | Yes |
| Product info (title, price) | Text | Via form fields |

## Output: 1080×1920 (9:16), up to 60s

## Key Rules
- Product-focused layout with price display
- Feature highlights from transcript
- CTA card for purchase action
- No background music by default (user's clip may have audio)
- Clean product showcase feel
