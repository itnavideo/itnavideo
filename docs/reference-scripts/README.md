# Reference Scripts

These examples define the preferred output shape for transcription cleanup, script planning, timeline JSON, and Remotion scene generation.

## Files

- `hinglish-video-reference.md` - English + Roman Hinglish reel format.
- `english-video-reference.md` - English reel format.

## Usage

- Groq transcription should preserve the spoken language style and avoid over-translating Hinglish.
- Planning output should be clear enough to split into Hook, Body, and CTA.
- Timeline JSON should use concise scene descriptions and short on-screen text.
- Remotion should treat subtitles and timeline overlays as separate layers to avoid duplicate paragraph text.
