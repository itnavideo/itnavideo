# Image-First Collage Reel Rules

Fresh reference rules for Video Explainer reels. These replace the earlier icon/card-heavy direction.

## Core Style

- Make reels like editorial social-media posters in motion, not app UI dashboards.
- Use real PNG images, normal photos, reusable images, background images, typography, sound effects, and music.
- Do not rely on icons. Avoid icon-led scenes.
- Use photo composition as the main visual language.

## Layout

- Top area: a clean 16:9 image or video frame, like a source/reference frame.
- Main area: a large subject image, cutout-style PNG, or strong topic-matched photo.
- Background: use a blurred, enlarged version of a related image or a soft premium photo background.
- Typography sits directly over the image composition when readable.
- Avoid UI-looking panels, debug labels, dashboard cards, and generic “key point” boxes.

## Image Use

- Prefer actual people, places, objects, exam scenes, documents, classrooms, banks, offices, products, and topic-matched photos.
- Use 3-7 strong images across a 30-60 second reel when topic needs visual variety.
- One scene should have one strong image idea.
- Use reusable images and direct images first. Use icons only when no photo/PNG can communicate the idea, and even then keep them hidden/secondary.

## Typography

- Use bold headline typography, handwritten/brush accent words, stamp-style words, and large readable labels.
- Text should feel designed into the image, not placed in a card.
- Use black/white text with one strong accent color per scene.
- Keep text short: 2-6 words for headline, one short support phrase if needed.

## Audio

- Every reel should have background music unless explicitly disabled.
- Use sound effects for transitions and emphasis: whoosh, boom, stamp, bell, typing, cash, warning, hit.
- SFX must match the scene beat, not play randomly.

## Avoid

- No giant floating icons.
- No icon taxonomy planning.
- No dashboard-style lower cards.
- No repeated generic cards.
- No sharp busy background behind small text.
- No “we will do this” planning text in the rendered video.
