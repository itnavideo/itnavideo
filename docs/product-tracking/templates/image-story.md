# Image Story

## What this template does
Legacy/paused concept for turning narration and images into a scene-by-scene visual story reel. This is not part of the current focused production dashboard unless it is intentionally revived.

## User Inputs
- Audio or video with speech
- Optional images
- Optional topic/title
- Style options if revived in the future

## Main Features
- Scene-by-scene image storytelling
- Text beat overlays synced to narration
- Cinematic motion such as subtle zoom and pan
- Potential fit for motivational, narrative, and podcast-style content

## Current Problems
- Paused/removed from current focused dashboard because output quality was not reliable enough.
- Image sourcing, scene planning, and visual consistency need a higher quality bar before users pay for it.

## Possible Future Problems
- If revived without a strong preview editor, users may waste credits on wrong images or poor scene choices.
- AI-generated or selected imagery can feel generic, off-brand, or mismatched to narration.

## Improvements Done
- 2026-06-28: Marked as paused in product tracking so it is not confused with active production templates.
- 2026-06-28: Product direction changed to quality over quantity instead of keeping many average templates.

## Improvements Pending
- Decide whether Image Story should be permanently deleted or rebuilt later.
- If rebuilt, require preview editor support for scene text, image replacement, crop, fit, and timing.
- Create a strict QA benchmark before re-adding it to dashboard.
