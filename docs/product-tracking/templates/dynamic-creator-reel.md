# Dynamic Creator Reel

## What this template does
Turns a talking-head creator video into a typography-led short reel using the creator video as the only visual source.

## User Inputs
- Creator/talking-head video with speech
- Optional topic/title
- Subtitle output language

## Main Features
- Full-screen creator video
- Dynamic typography and key phrase overlays from transcript
- No extra images, clips, stickers, or stock visuals
- Short-form pacing focused on text and creator presence

## Current Problems
- Typography must be checked against face position so text does not cover the creator too much.
- Needs strong preview/final parity because users judge this template visually.

## Possible Future Problems
- Long transcript phrases can make overlays feel crowded.
- Horizontal or poorly framed videos can crop the face if no safe framing logic is applied.
