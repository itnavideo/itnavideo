# Long Video Promo

## What this template does
Creates a short vertical promo reel for a long-form video using a promo clip, thumbnail, title, and optional duration details.

## User Inputs
- Promo audio or video clip
- Thumbnail image
- Promo title
- Optional channel/title metadata and duration

## Main Features
- Premium thumbnail-first promo layout
- Uploaded media used as the promo clip
- Title and optional duration badge
- Designed for YouTube, podcast, lecture, music, religious, and educational content promotion

## Current Problems
- Thumbnail crop/fit can be weak when users upload non-16:9 images.
- Long titles need continuous overflow testing on mobile and render output.

## Possible Future Problems
- Users may expect automatic long-video clipping, but current flow depends on a short uploaded promo clip.
- Optional metadata fields can become clutter if they are added back without being rendered clearly.
