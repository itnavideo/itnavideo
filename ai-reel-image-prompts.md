# AI Reel Image Prompts - Realistic Direct-Use Batch

Use this list for the next download batch.

Goal: create images that can be used directly in reels without Remotion needing extra borders, cards, mockups, heavy layout work, or rescue editing. Prefer realistic people-led scenes because faces, body language, and real situations feel more relatable than empty desks, chairs, abstract objects, or nature-only backgrounds.

Global rules for every prompt:

- Vertical 9:16, high resolution, realistic editorial photo style.
- Include real-looking people when it fits the topic.
- Keep the scene natural, premium, and social-media ready.
- Leave clean empty space in the upper third or one side for title overlay.
- No readable text, no fake letters, no logos, no watermarks, no brand marks.
- No real school, company, hospital, bank, government, or app names.
- No UI screenshots, no document text, no tiny dashboard details.
- Avoid collage, poster, infographic, flat lay, and product-only table scenes unless explicitly requested.
- Image should look complete if used full-screen with only a small title overlay.
