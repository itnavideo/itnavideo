## 🌍 Overview

**Itnavideo** is an AI-powered SaaS platform that converts voice recordings into professional short-form videos automatically.

No editing skills.  
No timelines.  
No complicated software.  

Just upload your voice — AI handles the rest.

- Instagram Reels (9:16)
- TikTok Videos (9:16)
- YouTube Shorts (9:16)

Our multi-modal AI engine:

- Optimizes safe zones

- Professional MP4 videos

# 🤖 AI Pipeline Architecture

```text
User Uploads Voice + Media
            ↓
OpenAI Whisper API
→ Speech-to-text
→ Word timestamps
            ↓
GPT-4o Audio
→ Mood detection
→ Tone analysis
→ Energy analysis
            ↓
GPT-4o Vision
→ Screenshot understanding
→ Face-aware cropping
→ Smart visual placement
            ↓
GPT-4o Text
→ Scene generation
→ Animation planning
→ Caption timing
            ↓
Canva API
→ Premium elements
→ Motion graphics
→ 2D/3D assets
            ↓
FFmpeg
→ Video rendering
→ Caption sync
→ Final MP4 generation
            ↓
Cloudinary
→ Storage
→ Compression
→ CDN delivery
```
